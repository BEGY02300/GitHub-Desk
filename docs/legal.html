Ne publie pas une adresse personnelle sans avoir vérifié les règles applicables à ta situation.

Responsable de publication : l’éditeur du projet, identité complète à renseigner.

Hébergement

GitHub Pages

Le site est servi par GitHub Pages. L’hébergeur peut traiter les données techniques nécessaires à la sécurité et à la fourniture du service selon ses propres conditions et politiques.

Documentation GitHub Pages · Politique de confidentialité de GitHub

Confidentialité

Données utilisées par le site

  • Le site n’intègre pas de publicité, d’outil de mesure d’audience ni de formulaire de collecte. Il n’installe pas de cookie de suivi ni de stockage local volontaire.
  • Pour afficher les versions et les derniers changements, la page d’accueil interroge l’API publique de GitHub depuis ton navigateur. GitHub reçoit donc la requête et les informations techniques habituelles associées à celle-ci ; consulte sa politique de confidentialité pour en savoir plus.
  • Les liens vers GitHub ou d’autres sites ouvrent leurs propres services et politiques. Cette page ne contrôle pas les données collectées par ces tiers.
  • L’application de bureau est distincte du site : son cache est conservé localement sur l’appareil. Les identifiants GitHub sont gérés par GitHub CLI ; consulte le code source et le README pour le détail des données locales.

Demandes relatives à la vie privée

Une adresse de contact dédiée n’a pas encore été fournie. Ces mentions doivent être mises à jour avec un moyen de contact avant la publication définitive. N’envoie pas d’identifiants, de jetons d’accès ou d’informations confidentielles dans les issues publiques.
