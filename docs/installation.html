Guide pas à pas

Installer GitHub Desk.

Choisis ton système, installe les composants nécessaires, puis connecte ton compte GitHub une seule fois.

Télécharger la dernière version → Retour à la présentation
Windows 10 et 11 · x64

Installer sur Windows

  1. Dans la dernière release, télécharge github-desk-windows-x64-vX.Y.Z.zip et SHA256SUMS-vX.Y.Z-windows.txt en remplaçant X.Y.Z par la version affichée.
  2. Vérifie que la somme affichée dans le fichier correspond au résultat de cette commande PowerShell : 
    Get-FileHash .\github-desk-windows-x64-vX.Y.Z.zip -Algorithm SHA256
  3. Décompresse l’archive dans un dossier. Garde ensemble GitHubDesk.exe et le dossier _internal, puis lance GitHubDesk.exe.
  4. Si WebView2 est absent, installe le runtime WebView2 officiel.

Installer GitHub CLI

Ouvre PowerShell et installe l’outil officiel utilisé pour l’authentification :

winget install --id GitHub.cli --exact

Git est facultatif, mais nécessaire pour les fonctions qui clonent ou archivent des dépôts :

winget install --id Git.Git --exact
Mac · architecture indiquée par la release

Installer sur macOS

  1. Télécharge github-desk-macos-ARCH-vX.Y.Z.zip et le fichier de sommes SHA-256 correspondant depuis les releases. Choisis l’archive dont l’architecture correspond à ton Mac.
  2. Dans Terminal, depuis le dossier contenant le téléchargement, vérifie l’archive : 
    shasum -a 256 github-desk-macos-ARCH-vX.Y.Z.zip
  3. Décompresse l’archive, puis déplace GitHub Desk.app dans /Applications.
  4. Installe GitHub CLI avec Homebrew, ou suis ses instructions officielles : 
    brew install gh
    Installe aussi Git si nécessaire avec brew install git.
Signature : les applications macOS publiées ne sont pas encore signées/notarisées. macOS peut donc afficher un avertissement. Ne désactive pas Gatekeeper pour contourner ce message ; attends une version signée ou utilise le code source si tu sais le lancer et le vérifier.
Linux · x86_64 · GTK 3 et WebKitGTK 4.1

Installer les dépendances Linux

Le build Linux est produit sur Ubuntu 24.04. Utilise une distribution 64 bits récente avec glibc 2.38 ou plus et WebKitGTK 4.1. Installe les dépendances de ta distribution avant de lancer l’application.

Debian 13+ et Ubuntu 24.04+

sudo apt update
sudo apt install gh git libgtk-3-0 libwebkit2gtk-4.1-0 python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1

Fedora 40+

sudo dnf install gh git gtk3 webkit2gtk4.1 python3-gobject

Arch Linux et distributions basées sur Arch

sudo pacman -Syu github-cli git gtk3 webkit2gtk-4.1 python-gobject

openSUSE Leap 16+ et Tumbleweed

sudo zypper refresh
sudo zypper install gh git gtk3 libwebkit2gtk-4_1-0 python3-gobject

Extraire et démarrer

Télécharge l’archive Linux et le fichier SHA-256 de la même release. Vérifie la somme, extrais l’archive et lance le programme depuis son dossier :

shasum -a 256 github-desk-linux-x64-vX.Y.Z.tar.gz
tar -xzf github-desk-linux-x64-vX.Y.Z.tar.gz
cd GitHubDesk
./GitHubDesk

Si la commande indique qu’il manque une bibliothèque, installe le paquet d’exécution correspondant avec le gestionnaire de ta distribution. La session graphique doit prendre en charge GTK 3.

Première utilisation

Connecter le compte GitHub

  1. Ouvre un terminal (PowerShell sous Windows, Terminal sur macOS ou Linux) et lance : 
    gh auth login
  2. Choisis GitHub.com, l’authentification par navigateur, puis suis les étapes affichées. Le navigateur s’ouvre uniquement pour cette connexion initiale volontaire.
  3. Vérifie que l’authentification est active : 
    gh auth status
  4. Lance GitHub Desk. L’application utilise la connexion enregistrée par GitHub CLI ; elle ne stocke pas le jeton dans son cache.
À savoir : seuls les dépôts auxquels ton compte possède déjà accès seront visibles. Git est requis pour cloner et archiver ; GitHub CLI sert aux fonctions GitHub.
Téléchargements vérifiables

Un avertissement de sécurité ?

Les builds ne sont pas encore signés par un éditeur. La somme SHA-256 permet de vérifier que le fichier téléchargé correspond à celui publié, mais ne constitue pas une signature. Ne désactive pas l’antivirus ou Gatekeeper pour lancer un fichier qu’ils bloquent. Consulte le code source et signale tout faux positif à l’éditeur concerné.
