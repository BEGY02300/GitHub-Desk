Guide pas à pas

Installer GitHub Desk.

Choisissez votre système puis votre façon d’installer : pas à pas avec vos fenêtres habituelles, ou au terminal avec les commandes pour récupérer la dernière version.

Installation guidée ↓ Mode terminal >_ Fichiers de la dernière version ↗ Retour à la présentation
Option 1 · sans commandes pour télécharger l’application

Choisissez votre système.

Les étapes ci-dessous utilisent le navigateur, l’Explorateur de fichiers ou le Finder. Il n’y a pas d’installateur caché : GitHub Desk se télécharge comme une archive à extraire.

Windows macOS Linux
Windows 10 et 11 · x64

Windows, avec l’Explorateur.

  1. Ouvrez la dernière version GitHub et téléchargez github-desk-windows-x64-…zip. Les fichiers SHA-256 sont sur la même page.
  2. Dans l’Explorateur de fichiers, ouvrez Téléchargements, faites un clic droit sur l’archive et choisissez Extraire tout….
  3. Ouvrez le dossier extrait. Gardez GitHubDesk.exe et le dossier _internal ensemble, puis double-cliquez sur GitHubDesk.exe.
  4. Si Windows signale que WebView2 manque, installez le runtime WebView2 officiel, puis relancez l’application.

Prérequis : le parcours graphique télécharge l’application, mais ne peut pas installer les outils système en arrière-plan. Pour installer automatiquement GitHub CLI, Git et WebView2, utilisez le script Windows guidé plus bas. La connexion GitHub reste une étape interactive effectuée une seule fois dans le navigateur.

macOS · choisissez l’architecture de votre Mac

macOS, avec le Finder.

  1. Ouvrez la dernière version GitHub. Téléchargez l’archive macOS et choisissez l’architecture indiquée pour votre Mac.
  2. Dans le Finder, ouvrez Téléchargements, puis double-cliquez sur l’archive ZIP pour l’extraire.
  3. Faites glisser GitHub Desk.app dans le dossier Applications, puis ouvrez l’application.
  4. Si macOS affiche un avertissement, ne désactivez pas ses protections. Les versions actuelles ne sont pas signées/notariées ; n’ouvrez pas une application bloquée par Gatekeeper.

Prérequis : le script terminal installe GitHub CLI et Git avec Homebrew. Homebrew doit être installé une première fois depuis le site officiel ; son installation demande confirmation et parfois le mot de passe administrateur. La connexion GitHub ouvre le navigateur une seule fois.

Linux · x86_64 · GTK 3 et WebKitGTK 4.1

Linux, avec le gestionnaire de logiciels.

Le build est produit sur Ubuntu 24.04. Utilisez une distribution x86_64 récente avec glibc 2.38 ou plus. Le parcours terminal peut installer les dépendances système avec le gestionnaire de paquets de votre distribution ; il demandera votre mot de passe administrateur avant toute installation.

Paquets requis pour Debian 13+ et Ubuntu 24.04+

Dans un terminal :

sudo apt update
sudo apt install -y gh git libgtk-3-0 libwebkit2gtk-4.1-0 python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1

apt update actualise la liste des paquets disponibles. apt install installe GitHub CLI, Git et les bibliothèques GTK/WebKit nécessaires à la fenêtre de l’application ; -y confirme les questions du gestionnaire après votre autorisation avec sudo.

Paquets requis pour Fedora 40+

Dans un terminal :

sudo dnf install -y gh git gtk3 webkit2gtk4.1 python3-gobject

dnf install installe GitHub CLI, Git et les bibliothèques GTK/WebKit requises. -y confirme les questions du gestionnaire après votre autorisation avec sudo.

Paquets requis pour Arch Linux et dérivées

Dans un terminal :

sudo pacman -S --needed github-cli git gtk3 webkit2gtk-4.1 python-gobject

pacman -S installe GitHub CLI, Git et les bibliothèques GTK/WebKit requises. --needed évite de réinstaller les paquets déjà présents ; sudo demande l’autorisation administrateur.

Paquets requis pour openSUSE Leap 16+ et Tumbleweed

Dans un terminal :

sudo zypper refresh
sudo zypper install --non-interactive gh git gtk3 libwebkit2gtk-4_1-0 python3-gobject

zypper refresh actualise la liste des paquets ; zypper install installe GitHub CLI, Git et GTK/WebKit. Votre mot de passe administrateur reste requis pour sudo.

Automatique : le script Linux ci-dessous détecte Debian/Ubuntu, Fedora, Arch ou openSUSE, installe les dépendances, télécharge la dernière version, vérifie son SHA-256 et la lance.

Option 2 · installation assistée au terminal

Installer automatiquement les prérequis.

Chaque script installe les outils requis via le gestionnaire officiel du système, se connecte à GitHub si nécessaire, télécharge la dernière version, vérifie son SHA-256, puis lance GitHub Desk. Les explications sont dans les commentaires du script. La première connexion peut ouvrir le navigateur ; l’installation des paquets système demande votre autorisation. Aucun antivirus ni contrôle de sécurité n’est désactivé.

Windows 10/11 · PowerShell

Ouvrez PowerShell et collez tout le script. winget installe les composants manquants ; Windows peut demander votre confirmation.

$ErrorActionPreference = "Stop"

# Vérifie que le gestionnaire de paquets Windows est disponible.
if (-not (Get-Command winget -ErrorAction SilentlyContinue)) {
  throw "Installez « App Installer » depuis le Microsoft Store, puis relancez ce script."
}

# Installe GitHub CLI, utilisé pour télécharger et connecter le compte.
if (-not (Get-Command gh -ErrorAction SilentlyContinue)) {
  winget install --id GitHub.cli --exact --accept-package-agreements --accept-source-agreements
  if ($LASTEXITCODE -ne 0) { throw "L'installation de GitHub CLI a échoué." }
}

# Installe Git, nécessaire aux fonctions de clonage et d'archivage.
if (-not (Get-Command git -ErrorAction SilentlyContinue)) {
  winget install --id Git.Git --exact --accept-package-agreements --accept-source-agreements
  if ($LASTEXITCODE -ne 0) { throw "L'installation de Git a échoué." }
}

# Installe le moteur de fenêtre WebView2 s'il n'est pas déjà présent.
$webViewRuntime = Get-ChildItem "HKLM:\SOFTWARE\Microsoft\EdgeUpdate\Clients", "HKLM:\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients" -ErrorAction SilentlyContinue |
  Get-ItemProperty -ErrorAction SilentlyContinue |
  Where-Object { $_.name -eq "Microsoft Edge WebView2 Runtime" } |
  Select-Object -First 1
if (-not $webViewRuntime) {
  winget install --id Microsoft.EdgeWebView2Runtime --exact --accept-package-agreements --accept-source-agreements
  if ($LASTEXITCODE -ne 0) { throw "L'installation de WebView2 a échoué." }
}

# Recharge PATH pour rendre visibles les outils qui viennent d'être installés.
$env:Path = [Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [Environment]::GetEnvironmentVariable("Path", "User")

# Demande une connexion uniquement si GitHub CLI n'est pas déjà connecté.
gh auth status *> $null
if ($LASTEXITCODE -ne 0) { gh auth login }
if ($LASTEXITCODE -ne 0) { throw "La connexion GitHub a échoué." }

# Télécharge la dernière archive Windows et son manifeste de sommes.
$downloads = Join-Path $HOME "Downloads"
New-Item -ItemType Directory -Force -Path $downloads | Out-Null
$folder = Join-Path $downloads ("GitHubDesk-" + [guid]::NewGuid().ToString("N"))
New-Item -ItemType Directory -Force -Path $folder | Out-Null
gh release download --repo BEGY02300/GitHub-Desk --pattern "github-desk-windows-x64-*.zip" --pattern "SHA256SUMS-*-windows.txt" --dir $folder
if ($LASTEXITCODE -ne 0) { throw "Le téléchargement GitHub a échoué." }

# Compare le SHA-256 de l'archive à celui publié dans le manifeste.
$archive = Get-ChildItem $folder -Filter "github-desk-windows-x64-*.zip" | Select-Object -First 1
$sums = Get-ChildItem $folder -Filter "SHA256SUMS-*-windows.txt" | Select-Object -First 1
if (-not $archive -or -not $sums) { throw "Archive ou manifeste SHA-256 introuvable." }
$line = Select-String -Path $sums.FullName -SimpleMatch $archive.Name | Select-Object -First 1
if (-not $line) { throw "Aucune somme publiée pour cette archive." }
$expected = $line.Line.Substring(0, 64).ToUpperInvariant()
$actual = (Get-FileHash $archive.FullName -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw "SHA-256 incorrect. N'ouvrez pas cette archive." }

# Extrait l'application dans Téléchargements et la démarre.
Expand-Archive -LiteralPath $archive.FullName -DestinationPath $folder -Force
Start-Process (Join-Path $folder "GitHubDesk\GitHubDesk.exe")
  • winget installe uniquement les outils absents : GitHub CLI, Git et le runtime WebView2.
  • gh auth login ouvre la connexion GitHub dans le navigateur seulement si nécessaire.
  • gh release download récupère l'archive et son manifeste ; Get-FileHash vérifie leur empreinte avant extraction.
  • Expand-Archive extrait les fichiers et Start-Process ouvre l’application. En cas d'erreur SHA-256, le script s'arrête.
macOS · Terminal et Homebrew

Installez d’abord Homebrew depuis son site officiel si votre Mac ne l’a pas. Cette étape demande une confirmation de votre part. Ensuite, collez tout le script dans Terminal :

#!/bin/bash
set -eu

# Homebrew fournit les outils système sans télécharger d'installateur tiers.
if ! command -v brew >/dev/null 2>&1; then
  echo "Homebrew est requis. Installez-le depuis https://brew.sh/, puis relancez ce script."
  exit 1
fi

# Installe GitHub CLI et Git uniquement s'ils sont absents.
brew list --versions gh >/dev/null 2>&1 || brew install gh
brew list --versions git >/dev/null 2>&1 || brew install git

# Connecte le compte uniquement si aucune session GitHub n'est active.
gh auth status >/dev/null 2>&1 || gh auth login

# Choisit l'archive correspondant au processeur du Mac.
case "$(uname -m)" in
  arm64|aarch64) arch="arm64" ;;
  x86_64) arch="x86_64" ;;
  *) echo "Architecture Mac non prise en charge."; exit 1 ;;
esac

# Crée un dossier temporaire dédié au téléchargement.
mkdir -p "$HOME/Downloads"
folder="$(mktemp -d "$HOME/Downloads/GitHubDesk.XXXXXX")"
cd "$folder"

# Télécharge la dernière archive macOS et le manifeste SHA-256.
gh release download --repo BEGY02300/GitHub-Desk --pattern "github-desk-macos-${arch}-*.zip" --pattern "SHA256SUMS-*-darwin.txt"
archive="$(find . -maxdepth 1 -name "github-desk-macos-${arch}-*.zip" -print -quit)"
sums="$(find . -maxdepth 1 -name 'SHA256SUMS-*-darwin.txt' -print -quit)"
test -n "$archive"
test -n "$sums"

# Vérifie l'archive avant de l'extraire ou de la lancer.
expected="$(awk -v name="$(basename "$archive")" '$2 == name {print $1; exit}' "$sums")"
actual="$(shasum -a 256 "$archive" | awk '{print $1}')"
if [ -z "$expected" ] || [ "$actual" != "$expected" ]; then
  echo "Échec SHA-256 : n'ouvrez pas cette archive."
  exit 1
fi

# Extrait l'application dans Téléchargements puis l'ouvre.
unzip -o "$archive" -d "$folder"
open "$folder/GitHub Desk.app"
  • brew install ajoute GitHub CLI et Git ; Homebrew demande l’autorisation requise par macOS.
  • gh auth login ouvre le navigateur uniquement lors de la première connexion.
  • uname -m choisit le paquet Apple Silicon ou Intel ; gh release download télécharge la version correspondante.
  • shasum -a 256 vérifie l’archive avant unzip et open. Le script n’essaie pas de contourner Gatekeeper.
Linux · Debian/Ubuntu, Fedora, Arch ou openSUSE

Collez le script dans un terminal. Il détecte la distribution, installe les paquets avec son gestionnaire officiel et vous demande le mot de passe administrateur pour sudo.

#!/bin/bash
set -eu

# Détecte l'identifiant de la distribution depuis le fichier système standard.
. /etc/os-release

# Installe les bibliothèques de fenêtre, GitHub CLI et Git avec le gestionnaire adapté.
case "$ID $ID_LIKE" in
  *debian*|*ubuntu*)
    sudo apt-get update
    sudo apt-get install -y gh git libgtk-3-0 libwebkit2gtk-4.1-0 python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1
    ;;
  *fedora*)
    sudo dnf install -y gh git gtk3 webkit2gtk4.1 python3-gobject
    ;;
  *arch*)
    sudo pacman -S --needed github-cli git gtk3 webkit2gtk-4.1 python-gobject
    ;;
  *suse*)
    sudo zypper --non-interactive refresh
    sudo zypper --non-interactive install gh git gtk3 libwebkit2gtk-4_1-0 python3-gobject
    ;;
  *)
    echo "Distribution non prise en charge automatiquement : $ID"
    echo "Consultez les prérequis Linux du guide avant de continuer."
    exit 1
    ;;
esac

# Ouvre la connexion GitHub uniquement si aucune session n'est active.
gh auth status >/dev/null 2>&1 || gh auth login

# Crée un dossier temporaire pour les fichiers de la dernière release.
mkdir -p "$HOME/Downloads"
folder="$(mktemp -d "$HOME/Downloads/GitHubDesk.XXXXXX")"
cd "$folder"

# Télécharge l'application Linux et le manifeste de sommes SHA-256.
gh release download --repo BEGY02300/GitHub-Desk --pattern "github-desk-linux-x64-*.tar.gz" --pattern "SHA256SUMS-*-linux.txt"
archive="$(find . -maxdepth 1 -name 'github-desk-linux-x64-*.tar.gz' -print -quit)"
sums="$(find . -maxdepth 1 -name 'SHA256SUMS-*-linux.txt' -print -quit)"
test -n "$archive"
test -n "$sums"

# Vérifie l'archive avant extraction et arrêt immédiat si elle diffère.
expected="$(awk -v name="$(basename "$archive")" '$2 == name {print $1; exit}' "$sums")"
actual="$(sha256sum "$archive" | awk '{print $1}')"
if [ -z "$expected" ] || [ "$actual" != "$expected" ]; then
  echo "Échec SHA-256 : ne lancez pas cette archive."
  exit 1
fi

# Extrait le paquet et démarre GitHub Desk.
tar -xzf "$archive"
cd GitHubDesk
./GitHubDesk
  • /etc/os-release identifie la distribution ; apt, dnf, pacman ou zypper installe automatiquement les dépendances requises.
  • sudo demande le mot de passe administrateur ; -y ou --non-interactive répond aux confirmations du gestionnaire après cette autorisation.
  • gh auth login ouvre la connexion GitHub dans le navigateur seulement si nécessaire.
  • sha256sum vérifie le téléchargement ; tar extrait ensuite l’application, qui est lancée depuis son dossier.

À retenir : ne lancez jamais l’application si une vérification SHA-256 échoue. Homebrew doit être installé séparément sur macOS ; le premier accès à GitHub et les autorisations administrateur nécessitent votre accord.

Première utilisation

Connecter le compte GitHub une première fois

  1. Installez GitHub CLI si ce n’est pas déjà fait, en utilisant les instructions de votre système.
  2. Ouvrez PowerShell (Windows), Terminal (macOS) ou un terminal (Linux), puis lancez gh auth login.
  3. Choisissez GitHub.com et l’authentification via navigateur, puis suivez les indications. Cette étape initiale ouvre votre navigateur pour la connexion.
  4. Après cela, utilisez GitHub Desk normalement : vous n’avez pas à saisir des commandes pour vos opérations quotidiennes.
À savoir : seuls les dépôts auxquels votre compte a déjà accès sont visibles. Git est requis pour cloner et archiver ; GitHub CLI sert à la connexion et aux fonctions GitHub.
Téléchargements vérifiables

Un avertissement de sécurité ?

Les builds ne sont pas encore signés par un éditeur. La somme SHA-256 permet de vérifier que le fichier téléchargé correspond à celui publié, mais ne constitue pas une signature. Ne désactivez pas l’antivirus ou Gatekeeper pour lancer un fichier qu’ils bloquent. Consultez le code source et signalez tout faux positif à l’éditeur concerné.
